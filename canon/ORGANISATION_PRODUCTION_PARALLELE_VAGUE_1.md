# ORGANISATION DE PRODUCTION PARALLÈLE
## The Society Group — 1er août 2026

## Règle de production

La consolidation se fait désormais par vagues de quinze métiers :
- Lot A : cinq métiers de direction et gouvernance.
- Lot B : cinq métiers industriels et opérationnels.
- Lot C : cinq métiers numériques, data ou transformation.

Chaque lot avance en parallèle sur :
1. récupération des fragments existants ;
2. contrôle du personnage et de la chronologie ;
3. fusion et correction ;
4. enrichissement documentaire ;
5. préparation du chapitre complet ;
6. préparation de l’illustration individuelle.

## Critères de sortie obligatoires

Pour chaque métier :
- [ ] texte source retrouvé ;
- [ ] illustration ou prompt source retrouvé ;
- [ ] personnage confirmé ;
- [ ] âge et parcours cohérents ;
- [ ] tome et période confirmés ;
- [ ] événement de saga confirmé ;
- [ ] journée complète ;
- [ ] frise du métier ;
- [ ] responsabilités, limites, outils et collaborations ;
- [ ] études, marché, salaire et mobilité ;
- [ ] cas concret ;
- [ ] impact de l’IA ;
- [ ] futur à dix ans ;
- [ ] transition narrative ;
- [ ] prêt à illustrer ;
- [ ] frise maître mise à jour ;
- [ ] registre du canon mis à jour.

## Règle d’arrêt

Aucun lot n’est déclaré terminé tant que les critères ci-dessus ne sont pas cochés pour chacun des cinq métiers.
