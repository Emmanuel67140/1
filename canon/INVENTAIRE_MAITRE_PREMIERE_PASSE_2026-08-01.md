## 4. Règles de reprise d’un métier

Chaque métier retrouvé doit être classé :
- [ ] Conserver.
- [ ] Adapter.
- [ ] Réécrire.
- [ ] Fusionner.
- [ ] Supprimer.

Chaque chapitre doit ensuite comporter :
- [ ] un métier unique ;
- [ ] un personnage principal unique ;
- [ ] une histoire dans la saga ;
- [ ] une double page d’ouverture ;
- [ ] une journée complète de bout en bout ;
- [ ] une frise chronologique du métier ;
- [ ] responsabilités, limites, outils et collaborations ;
- [ ] études, marché, salaire et mobilité ;
- [ ] cas concret ;
- [ ] impact de l’IA ;
- [ ] futur à dix ans ;
- [ ] transition narrative ;
- [ ] illustration individuelle conforme ;
- [ ] mise à jour de la frise générale ;
- [ ] sauvegarde dans le dépôt.

## 5. Premier lot réellement prioritaire après audit

Le premier lot ne doit pas reprendre des métiers déjà bien développés sans nécessité. Il doit traiter les trous confirmés de la gouvernance :

1. Président du conseil.
2. Administrateur indépendant.
3. Secrétaire du conseil.
4. Directeur de cabinet.
5. Assistante exécutive.

Avant rédaction, pour chacun :
- retrouver toute trace existante ;
- vérifier s’il existe déjà une illustration ;
- confirmer le personnage ;
- rattacher le métier à un événement précis du tome 3 ;
- éviter tout doublon avec le PDG, le DG, le conseil d’administration ou le COMEX.
